# Firewatch Home 3.1.0 — experimental community preview 1

A standalone native LG webOS launcher with 42 landscapes, seven times of day, seasonal artwork, animated scenery, and remote-friendly Appearance and Apps & Inputs controls.

**Experimental pre-release. Locally tested, but not yet validated on a fresh TV.** The screenshots show the personal development installation. This package does not include its default-Home takeover, startup optimisation, global remote mapping or screensaver helper. There is no universal compatibility or five-second startup claim.

## Download

- `uk.local.minimalhome.native_3.1.0_arm.ipk` — prebuilt 32-bit ARM app, including all artwork. No compiler needed.
- `uk.local.minimalhome.native_3.1.0_arm.ipk.sha256` — package checksum.
- `firewatch-home-3.1.0-preview-tools.zip` — small installer kit with `START-HERE.md`, Python tools and recovery/testing instructions.
- `SHA256SUMS.txt` — SHA-256 for the package, installer kit and manifest.
- `uk.local.minimalhome.native_3.1.0_arm.manifest.json` — per-file build manifest.

## Start here

1. Use an already-rooted **test TV**, with root SSH access, Homebrew Channel persistence, a 32-bit ARM runtime, LG's native `qml-runner` and the necessary LG Qt/Luna modules. This release does not root a TV or grant system permissions.
2. Download the IPK, its `.sha256` file and the installer kit above. Extract the kit and place the IPK and checksum beside `START-HERE.md`.
3. Read `START-HERE.md`. Run the dry-run plan first, followed by the read-only doctor. Install only if you understand the limitations and the prerequisite checks pass.
4. Open Firewatch Home from LG Home. Use Apps & Inputs to arrange your shortcuts. Back closes panels; Red opens stock Home while the app is active.
5. [Report your test result](https://github.com/josephkimberley/firewatch-home/issues/new?template=preview-report.yml), including model, firmware and app version. Remove IP addresses, credentials and other personal details from logs.

The installer refuses an existing `uk.local.minimalhome.native` installation. There is no supported upgrade/rollback manager yet. Remove this standalone app through LG Home's app management; app-owned preferences may remain. Stop if runtime checks fail instead of bypassing them.

No TV? [Try the desktop mock](https://github.com/josephkimberley/firewatch-home/blob/v3.1.0-preview.1/preview/README.md), or [explore all artwork](https://josephkimberley.github.io/firewatch-home/).
